Core

沙皇视角先记住这五句话

这场决赛不是“沙皇无脑拍装备”赢下来。Ai.po.tu选手面对的是连主带备大量拆装备、还能用菲兹反复复用拆装节奏的皎月。真正的胜负点在于：装备被拆以后，沙皇还能不能继续把费用、武装和沙兵压力接上。

装备要有第二层库存

皎月会用化为灰烬、折戟再战和菲兹反复打装备。沙皇不能只靠第一把武装，要准备连续补装的节奏。

皎月卡手时必须压分

第一局皎月费用和单位都不顺，沙皇靠装备不断给战场压力，逼皎月只能拆却很难反推。

蔑视要留给法术链

解说赛前就点出绿色蔑视能反制皎月关键法术。决胜局最后蔑视压住对手最后机会，才有沙兵现身收局。

沙兵现身不是唯一赢法

第一局和第二局前段都反复说明：沙皇可以靠沙皇本体、沙兵带刀和装备基本功抢分，不必每局都等大招。

领先时不要乱交资源

决胜局后段，放逐之刃选手手牌枯竭，沙皇要做的是保留蔑视和最后的沙兵现身，而不是给对手新的交换窗口。

Framework

沙皇框架：让皎月拆不完，也接不住

全场通用

沙皇 VS 皎月的目标不是保护每一件装备，而是让皎月每次拆装都付出费用、手牌和节奏。只要下一件装备、下一个沙兵或下一次沙兵现身还能接上，拆装就不是终点。

  1. 1

    先压费用

    皎月慢、单位少。前两回合不要只存资源，先把她逼到每回合都要拆装或补单位。

  2. 2

    装备分批交

    不要把所有武装堆在同一条线。对手有菲兹和化为灰烬时，分散压力比单点爆发更稳。

  3. 3

    把蔑视写进曲线

    皎月的关键法术链会围绕减战力、拆装和回手展开。蔑视要留给能改变整回合结算的位置。

  4. 4

    最后再交收局牌

    领先时不要提前亮沙兵现身。等皎月手牌少、费用紧或最后一张牌被蔑视压住，再收口。

沙皇每回合先问这三个问题

  • 这件装备被拆以后，我下一回合还有没有装备、沙兵或英雄本体继续给压力？
  • 皎月现在拆装是在解决问题，还是只是被迫延缓我的分数？
  • 我手里的蔑视是不是唯一能挡住皎月下一条法术链的牌？

沙皇玩家可以直接照着练的清单

每回合都做的四个判断

皎月这回合拆我装备，会不会因此失去补单位或抢分的费用？
我下一件装备、下一只沙兵或下一张补强牌在哪里？
蔑视现在交是为了保小优势，还是为了封住对手关键法术链？
沙兵现身如果现在打，收益够不够；如果等一回合，皎月还能不能处理？

关键牌使用规则

低费武装 把它当作连续压力，不要当作一次性爆发。皎月拆第一件时，你要能马上补第二件。
沙皇本体 皎月缺费用或缺单位时可以主动顶上去压分；皎月手牌充足时要防专属法术和拆装链。
和平卫士 / 主动单位 用于提前制造战场压力，让皎月不能只把全部费用留给拆装备。
蔑视 留给皎月关键法术链，尤其是对方试图用最后一张牌争回战场或压住沙兵现身时。
沙兵现身 不要因为手里有就早打。等对手拆装资源、单位和手牌都被压低，再作为最后收口。
Review

沙皇玩家最容易犯的错

  • 把皎月的拆装理解成“不能打装备”，导致自己先停手。
  • 同一回合把装备堆得太集中，被菲兹和化为灰烬一串拆完。
  • 领先时急着交蔑视或沙兵现身，给皎月留下最后一轮回手和反打空间。
  • 只算沙兵现身的峰值，不算装备被拆以后沙兵还有多少实际战力。
  • 看到皎月手牌少却不敢继续压分，让对手用过牌慢慢补回资源。

这场对沙皇玩家最有价值的地方，是它展示了被针对时的赢法：你会被拆装备，但只要装备、费用、反制和沙兵现身能形成连续压力，皎月仍然会被迫先耗尽资源。

Core

皎月视角先记住这五句话

放逐之刃选手的皎月牌表非常明确：用大量拆装备、菲兹复用和回手链去拆沙皇武装。但这场也说明了皎月的代价：如果只拆不铺、只解不补牌，沙皇会用下一轮装备和沙兵继续压分。

拆装不是胜利条件

拆掉装备只是把沙皇速度降下来。你还要有单位、战场和后续手牌，才能把比赛转成自己的节奏。

菲兹是资源引擎

菲兹配合折戟再战、化为灰烬能连续拆装，但也会消耗手牌和费用。用它之前要算下一回合还能不能补场。

强买强卖要压蔑视窗口

第二局和第三局都能看到，皎月需要让沙皇没法舒服地开蔑视。否则关键专属法术会被一张牌挡住。

单位密度决定能不能活过中期

决胜局皎月拆得漂亮，但单位数量和手牌都很紧，最后只能看着沙皇重新组织收局。

扳回一城靠的是完整资源链

第二局不是单张牌赢，而是战场、回手、强买强卖和单位都到位，才让沙皇压力变得可处理。

    给沙兵现身留答案

    前期拆装可以积极，但最后必须留牌处理沙兵现身。手牌打干后，皎月很难接收局。

Practice

皎月玩家可以直接照着练的清单

每回合都做的四个判断

我这次拆装之后，能不能补单位或抢一个战场分？
菲兹复用拆装牌以后，我下一回合还有几张手牌可以继续打？
沙皇是否留着蔑视？我的关键法术能不能先骗出或避开它？
我有没有为最后的沙兵现身保留答案，而不是把所有资源用在前中期？

关键牌使用规则

化为灰烬 优先拆会改变沙兵现身收益或沙皇本体战力的装备。不要只为止损而拆，最好同时制造反推窗口。
菲兹 用来复用关键拆装或保护节奏。常见误用是过早投入，结果只拆了装备却没有单位承接。
折戟再战 适合和菲兹组成连续拆装回合，但要提前算手牌和费用，避免后续无法补场。
强买强卖 最好的窗口是压住沙皇蔑视或关键回应费用，让自己的专属法术和回手链能通过。
造化弄人 第二局的收口牌。不要只当保命回手，要用来把已经稳定的场面转成胜势。
Review

皎月玩家最容易犯的错

  • 看到装备就拆，但拆完没有补单位，导致沙皇下一回合继续压分。
  • 菲兹和化为灰烬投入太早，换来装备消失，却把自己的手牌打空。
  • 没有把强买强卖写进曲线，让关键法术直接撞进沙皇蔑视。
  • 只防沙皇本体，不给沙兵现身预留最后答案。
  • 为了前中期止损交光回手，真正需要造化弄人收局时没有资源。

这场对皎月玩家最有价值的地方，是它同时展示了拆装构筑的强度和代价。你能把沙皇装备拆空，但只有拆装、单位、手牌和终局答案同时在线，才能真正赢下沙皇。
