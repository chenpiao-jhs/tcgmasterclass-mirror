Core

妖姬视角先记住这五句话

这场 DWT-阿龙选手赢在连续压力，而不是单次爆发。赛后数据页显示妖姬方映像打出 10 次，官方全场 KEY 牌给到蔚，和平卫士；这两个画面合起来说明，妖姬真正的胜路是先用映像和场地把回合滚起来，再用蔚这种高质量单位把卡兹克防线压穿。

映像不是装饰，是回合长度

妖姬方映像次数明显领先，意味着每一轮都在多创造交换点。练这套牌时，不要把映像只当复制战力，而要当成延长完整回合的资源。

场地先把资源接住

暮色玫瑰实验室和希拉娜修道院都出现在对局信息里。妖姬要先让资源有落点，再谈击杀和追分，否则手牌会停在手里。

卡兹克在场时别单点送

卡兹克方最强的防守价值，是迫使妖姬不能一个一个给它成长机会。妖姬进攻前要把同轮多点压力算好。

蔚负责把优势结算掉

全场 KEY 牌给到蔚，和平卫士，不是因为她只赢了某一次战斗，而是因为她把妖姬前面积累的映像和节奏优势变成最终比分。

比分咬住时别急着收

第一局中后段比分一度很紧，妖姬要做的是继续逼卡兹克分配防守，而不是把所有资源压在一条能被反应牌打断的路线里。

Review

妖姬玩家最容易犯的错

  • 把映像当成一次性加压，没有规划下一轮资源落点。
  • 看到卡兹克在场仍然单点推进，给对手最舒服的成长和防守方式。
  • 场地已经翻出，却没有安排能承接场地收益的单位。
  • 紧分时只追当前一分，忽略下一轮是否还拥有第二条路线。
  • 蔚过早进场，被卡兹克方反应牌集中处理，没能成为收口单位。

这场给妖姬玩家的核心课是：先用映像和场地把回合拉长，再用蔚这样的高质量单位把资源优势结算掉。不要把所有胜负压在一次看起来很大的进攻里。

卡兹克视角先记住这五句话

Zugo选手这场的难点，是妖姬方把问题拆成了多条线。卡兹克不是不能防，而是不能只防当前最大单位；一旦每次防守都只换掉一个威胁，DWT-阿龙选手的映像和场地就会把下一轮继续接上。

让卡兹克改变对手排序

卡兹克在场的价值，是让妖姬不能随便单点推进。如果对手仍然能舒服地一个个推进，卡兹克就没有兑现防守压力。

防守后必须反问

解掉一个映像不够。卡兹克方每次防守后都要立刻制造得分、经验或资源窗口，否则只是让妖姬晚一点赢。

蔚进场前要留答案

官方 KEY 牌给到蔚，和平卫士，说明卡兹克方没有把最终收口点拦住。复盘时要问蔚进场前答案花在哪里了。

Framework

防守框架：不要让妖姬把每轮都打成多选题

全场通用

卡兹克方对妖姬，真正要防的不是某一个最大单位，而是妖姬的回合长度。只要妖姬每轮都能多做一到两件事，卡兹克就会一直处在被动分配资源的位置。

  1. 1

    先标记资源承接点

    暮色玫瑰实验室、希拉娜修道院和能承载映像的单位，优先级高于普通战力点。

  2. 2

    用卡兹克约束排序

    卡兹克不能只是站着等交换。它要让妖姬担心单点推进被惩罚，从而迫使对手多付费用或分散资源。

  3. 3

    防守后立刻反问

    每次挡住映像以后，下一步必须是经验、得分或手牌优势。只清场不反推，会被妖姬继续补问题。

  4. 4

    蔚进场前保留硬答案

    如果把答案都交在小交换上，最后面对蔚，和平卫士时就只能看她把优势结算。

卡兹克每回合先问这三个问题

  • 这回合真正延长妖姬回合的是哪一个点：场地、映像，还是承载单位？
  • 我的卡兹克有没有迫使妖姬改变排序，还是被对手绕开了？
  • 如果蔚下回合进场，我是否还有能处理她的费用和答案？

关键牌使用规则

虚空掠夺者卡兹克 不要只当防守身材。它的角色是惩罚妖姬单点推进，并逼对手改变整个进攻排序。

中型防守单位 要和卡兹克一起形成防线，不能一个一个被映像或高质量单位拆掉。
经验获取路线 赛后数据页显示卡兹克方有经验获取，但没有转成胜势。经验要服务于下一轮主动权，不是独立收益。

Review

卡兹克玩家最容易犯的错

  • 只处理当前最大单位，没有处理妖姬下一轮的场地或映像承接点。
  • 让卡兹克站场后没有改变对手排序，导致它只是普通防守单位。
  • 防守以后没有反问，经验和资源没有转成主动权。
  • 硬答案过早交在小交换上，最后无法处理蔚，和平卫士。
  • 紧分局只算当前分差，没有提前砍掉妖姬第二条得分路线。

这场给卡兹克玩家的核心课是：防守必须换主动权。只要妖姬的映像和场地还能把下一轮接上，你处理掉一个威胁也只是延后问题。
