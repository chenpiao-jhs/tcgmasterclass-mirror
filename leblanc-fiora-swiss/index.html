Core

先记住这场对局的五句话

这不是一场“剑姬数值大所以赢”的比赛。妖姬三局都有资源爆发点，真正决定胜负的是资源能不能落到单位上、关键单位能不能避开决斗窗口、备牌能不能在正确费用回合变成场面。

资源牌先找承载点

艾克、峡谷先锋、千尾和映像不是“抽到就强”。先问场上有没有单位能承接收益，没有承载点时，手牌再多也只是待结算资源。

别把艾克卖成一次性牌

艾克加牺牲是能连续滚资源的组合。为了当回合小交换过早交掉艾克，后面就会变成有牺牲却没有稳定目标。

关键单位别后置到决斗窗口

妖姬最容易误判的是“我最后落艾克很安全”。只要剑姬还有费用和时点，后置关键单位反而会被决斗抓掉。

备牌要先排落地回合

和平卫士不是“抽到就完成针对”。它要在剑姬还没把分差和装备压力固定前落地，否则只会变成手牌里的正确答案。

加时前按两分差规划

瑞士轮进入加时时，领先两分才能直接获胜。妖姬玩家要提前两回合算追分路线，不能到最后才临时找一分。

打法框架：先保承载点，再把资源爆发打成连续回合

妖姬打剑姬的核心不是“这回合能不能抽很多牌”，而是先保住承载资源的单位，再决定艾克、牺牲、峡谷先锋、千尾和聚首要在哪个回合一起结算。

  1. 1

    先数承载单位

    每回合开始先数场上和手里能承接资源的单位。少于两个时，不要轻易把艾克或高质量单位卖进小交换。

  2. 2

    再算决斗窗口

    关键单位落场前，先问剑姬还剩几费、有没有最后行动时点。不能只看自己这一手舒服。

  3. 3

    把备牌排进费用曲线

    和平卫士这类针对牌要提前安排落地回合。等对手已经领先并装备成形，针对牌再正确也太慢。

  4. 4

    用两回合规划追分

    加时规则要求两分差。妖姬要提前准备连续两个得分回合，而不是把全部希望压在最后一张千尾上。

妖姬每回合先问这三个问题

  • 我现在的资源牌有几个可承载目标？如果目标被决斗，下一回合还能不能继续发动？
  • 剑姬这回合有没有费用打决斗、击退或回手？我是不是把关键单位放进了最危险的时点？
  • 我这一分是必须现在拿，还是应该先把和平卫士、提灯或聚首排进下个回合？

Game 2

第二局：换形态不是换牌名，而是换赢法

34:51 - 50:49

第一局的问题是资源太集中在少数承载点上，艾克和后场单位一断，妖姬就会空转。第二局的调整方向是正确的：Yankim1选手转向黄色妖姬、提灯和聚首，把胜路从单点爆发改成连续资源，降低被决斗和回手一张牌打断的损失。

这一局要学“换赢法”，不是只学换牌

第一局遗留问题 妖姬已经证明自己能抽、能复制、能打资源，但单个承载点太容易被剑姬处理。第二局调整要解决的是“被切一张就断档”的结构问题。
换备后的目标 黄色妖姬、提灯和聚首让资源分散到多个回合。对妖姬玩家来说，这比多塞一张强牌更重要，因为剑姬最擅长惩罚单点爆发。
中盘处理 45:15 附近压力不大时，千尾的价值不是马上抢一分，而是补出下回合完整资源链。领先或均势时，妖姬要先保证下回合还有承载点。
复盘标准 不要只问“这张提灯赚不赚”。要问：它有没有让剑姬的决斗变差？有没有让回手只处理一部分资源？有没有让下一回合仍然能展开？

Practice

妖姬玩家练习清单

每回合开始先数承载点：场上和手里至少要有两个能接资源的单位，再考虑艾克、牺牲和千尾。
后置关键单位前先报一遍：剑姬剩余费用、可能的决斗、击退和回手时点。
备牌局把和平卫士这类针对牌写进费用曲线，确认它应该在哪一回合落地，而不是抽到后临时找机会。
进入加时前两回合就开始算两分差，避免最后只剩一张千尾或一个不完整追分窗口。

关键牌使用规则

艾克 把它当成连续资源发动机，而不是普通交换牌。落场前先确认剑姬是否还有决斗窗口；如果艾克被解后没有第二承载点，这回合通常不该把它暴露给对手最后行动。
牺牲 只有在目标退场后还能继续展开时才主动开。牺牲不是单纯多抽一张，而是配合艾克、映像和后续单位把手牌转成场面；没有承载点时先补单位。
提灯 / 聚首 备牌后用来分散资源压力。对手决斗和回手多时，不要把胜负压在单个大单位上，而是用提灯和聚首把资源拆到多个回合。
和平卫士 换备时就写清楚落地回合。它要在剑姬装备和分差固定前进场，才能惩罚前排规划；如果已经卡手，要立刻改算千尾、映像或连续追分路线。
千尾 / 映像 领先或压力小时先补完整回合，不急着把资源立刻换成一分。落后和加时时，它们要服务于连续两次追分，不能只完成一次漂亮爆发。
Avoid

妖姬玩家常见错误

  • 把手牌数量当优势，没有检查这些牌有没有单位可以承载。
  • 把艾克当成普通交换牌，忽略它对后续牺牲和复制的发动机价值。
  • 关键单位后置时只看自己舒服，没有先算剑姬最后行动窗口。
  • 备牌选对了，但没有设计落地回合，导致针对牌卡在手里。
Core

剑姬视角先记住这五句话

雷汐选手这场赢得不像单纯“剑姬身材更大”。真正值得剑姬玩家学的是：先逼妖姬把资源交到不舒服的位置，再用决斗和击退切断承载点，最后把领先分差守到加时规则生效。

妖姬怕的不是亏牌，是没目标

对资源套牌，不一定要把每张牌都赚回来。只要让对手没有单位承载资源，抽牌和映像就会延迟成低效手牌。

决斗要打在最后可控窗口

先处理能创造时点的单位，再交决斗。这样不是为了好看，而是为了让妖姬不能用费用和反应把场面救回来。

击退是限制器，不只是防守牌

击退能约束妖姬专法、暗刃和关键互动。你保留它，对手就不能放心把资源全部压在一条线上。

装备是为了逼资源错位

暴风大剑和武装装配的价值，不只是战力变大，而是逼妖姬把解牌、映像和单位交在你能处理的位置。

领先后别给连续追分

第三局进入加时前，领先方最怕的不是被拿一分，而是给妖姬连续两次追分窗口。守路线比贪扩大优势重要。

Plan

防守框架：先逼资源错位，再用决斗和击退封路线

剑姬打妖姬不能只想着“我这一刀能不能赢战斗”。更稳的路线是先用装备逼妖姬交资源，再用决斗处理承载单位，用击退约束关键法术，最后守住两分差。

  1. 1

    先逼对手交资源

    装备和高战力单位的目的，是让妖姬不能只舒服过牌，必须先交解牌、映像或承载单位。

  2. 2

    再切承载点

    妖姬一旦把资源落到艾克、峡谷先锋或后场单位上，决斗要打在它能继续滚资源之前。

  3. 3

    保留击退约束法术

    击退不一定马上交。它在手里时，妖姬每次投入专法、暗刃和关键互动都要多承担一层风险。

  4. 4

    领先后守路线

    加时规则下，领先方更重要的是关掉对手连续追分路线，而不是每回合都追求最大收益。

剑姬每回合先问这三个问题

  • 妖姬现在真正能承载资源的单位是哪一个？我能不能用排序或决斗先处理它？
  • 我手里的击退是必须交，还是留着就能让妖姬不敢全压关键法术？
  • 如果已经领先，我这回合是在扩大优势，还是在冒险给妖姬连续追分窗口？
Game 1

15:48 - 29:24

第二局妖姬不再把胜负完全压在单个发动机上，而是通过黄色妖姬、提灯、聚首和千尾把资源拆到多个回合。剑姬这边要学的是：当对手不再怕单张决斗时，你要从“切一个点”改成“压缩对手完整回合”。

这一局剑姬要换的不是牌，而是防守目标

对手变化 妖姬换成更分散的资源结构后，一张决斗很难像第一局那样直接打断全部资源链。剑姬要接受这个变化，不要继续寻找单点全解。
防守目标 重点变成压缩妖姬的完整回合：让提灯和聚首只能补一半，让千尾补牌后没有足够费用继续站场，让黄色妖姬复制出来也缺落点。
资源交换 第二局中段妖姬压力较小时可以先补资源。剑姬要在这里判断自己是否还能用装备逼迫对手提前交牌，而不是等妖姬把下回合也组织好。
复盘标准 不要只看有没有解掉关键单位。要看这一回合结束后，妖姬下一回合是否还同时拥有费用、承载点和手牌。如果三件事都齐，剑姬就没有真正压住回合。

Practice

剑姬玩家练习清单

妖姬手牌多时，先数它场上能承载资源的单位，不要被手牌数量吓到。
每次决斗前先排顺序：先断能创造时点的单位，再处理真正发动机。
击退能不交就先不交，留在手里本身就会限制妖姬专法和暗刃。
加时领先时，所有防守都围绕“不给连续追两分”展开，而不是单纯守当前一分。

关键牌使用规则

决斗 优先打在艾克、峡谷先锋或能继续承载资源的单位上。不要为了小赚战斗过早交，先用排序压掉妖姬反应窗口，再在最后可控时点处理发动机。
击退 它在手里时就是限制器。除非能直接断掉妖姬关键回合，否则可以先保留，让对手不敢把专法、暗刃和映像全部压到同一条线。
暴风大剑 / 武装装配 装备不是只为了把数值堆高，而是逼妖姬先交解牌和承载单位。装备压力已经迫使对手资源错位时，下一步要转去切承载点。
坚毅不倒 留给妖姬必须连续追分的回合。它的价值不是多守一次小交换，而是让对手最后一波资源无法同时处理战斗和分差。
防反与收口牌 第三局后段先问“这张牌能不能阻止连续追两分”。领先时不要为了扩大优势把防反交空，先拆妖姬的费用、承载点和后续回合。
Avoid

剑姬玩家常见错误

  • 只堆装备，不处理妖姬真正能承载资源的后场单位。
  • 决斗顺序太急，反而给妖姬留下费用或时点补救。
  • 看到妖姬手牌多就急着抢分，忘了没有场面时这些牌很难兑现。
  • 加时领先后继续贪扩大优势，给对手留下连续追分窗口。

这场第七轮最适合拿来练两个基本功：妖姬玩家练“资源必须有承载点”，剑姬玩家练“不要和资源套牌比手牌，要处理它的承载单位”。能把这两件事看清，这场比赛就不只是结果复盘，而是一套可以带回牌桌的对局训练。
