Core

德莱文视角先记住这五句话

NGNL·雨辰选手赢下这场，不是因为每局都打得更顺。第一局后手第一回合空过仍然拿下，第二局被福州晖宸土豆揍bob选手扳回，第三局再靠先手、分差和小鲨鱼把死三回合锁住。德莱文玩家要学的是：红紫不是只拼爆发，而是要知道什么时候把一分先放进袋子里。

先守住分差，再谈大回合

第三局时间很紧，德莱文不是必须赢每一次战斗。只要能稳定领先两分，雷恩加尔最后一轮就很难追完。

责退和回手是保险，不是炫技

面对雷恩加尔、枯萎战斧和决斗，德莱文要把责退、换换乐、驭风而行当成保险线，专门防对手把一个点做成不可逆的大分。

小鲨鱼负责结算小分

终局小鲨鱼打掉伊焚娜那一路，让德莱文来到六分。不要小看这种低成本得分，它是计时局最稳的收口方式。

手牌差时要早点止损

第二局解说点出德莱文手牌结构差，且前期忘记触发对面战场。手牌不支持大回合时，先少输一分比强行找爆发更重要。

枯萎战斧是双方共同考点

全场 KEY 牌给到枯萎战斧。德莱文能用它补战力，雷恩加尔也能用它制造压力，所以每次战斧进场都要问：这次装备会不会真的转成分？

Practice

德莱文玩家复盘清单

  • 每轮开始先问：这一分必须争吗，还是可以用更低成本在另一边拿回来？
  • 面对雷恩加尔留橙红费用时，先假设对方有先打再问、顺劈、决斗或击退。
  • 手牌差时优先保留责退、换换乐或驭风而行，别把所有牌都投入同一路肉搏。
  • 进入死三前先算分差。领先两分时，小单位稳定拿分比大装备更重要。
  • 对手漏触发或错交资源后，立刻把优势换成分，不要给下一轮重新整理手牌的机会。
枯萎战斧 用于补足关键战力或逼对方交击退。不要在没有承载点保护时先把它暴露成对方的计算目标。
责退 / 换换乐 留给雷恩加尔叠高的一路，尤其是带战斧、决斗或击退保护的回合。不要提前交在普通小分上。
小鲨鱼 计时局的收分工具。用来打掉低战力一路、扩大分差，而不是硬塞进已经会被处理的主战场。
旋转飞斧 优先服务于“这一分会改变终局分差”的回合。单纯赢一个不影响轮次的战斗，通常不值得交。
Review

德莱文玩家最容易犯的错

  • 把每个雷恩加尔进攻都当成必须接，导致自己的回手和责退太早打空。
  • 手牌不好时还想打完整大回合，没有先把下一轮的分差安全线留出来。
  • 忘记对方战场或传奇触发，让本来能止损的一分变成连续失分。
  • 看到枯萎战斧就只想拼数值，忘了红紫还有改结算的路线。
  • 死三回合没有先算“领先几分够赢”，结果把稳定得分换成了不必要的高风险交换。

这场给德莱文玩家的核心课是：红紫可以打肉搏，但不能被肉搏牵着走。你要把小分、回手和计时压力串起来，让雷恩加尔每次大投入都只能追到你已经离开的地方。
