Core

皎月视角先记住这五句话

火星.化作蝴蝶飞舞选手赢得很干净：皎月没有和蔚正面比战力，而是用折戟再战拆装备、用月之降临和换换乐改变结算方式，再用彗、薇古丝和废弃大厅把蔚最想要的过量伤害窗口挡住。

先拆装备，再拆回合

蔚靠海克斯科技护手、枯萎战斧和大体型单位把数值滚起来。皎月第一局先把装备轴切断，蔚就很难把手里的力量落到战场上。

法盾不是不能打

第一局蔚连续用烬、狮子狗和魄罗这种法盾单位试探，皎月仍然愿意交高费用法术。只要交换后能保住节奏，倒法盾本身就是赚时间。

别给蔚过量伤害

第二局最重要的防守不是硬吃大哥，而是让蔚的攻击达不到过量三。不给超杀，蔚就少一次活跃、游走和捕猎场收益。

折戟再战是战术核心

官方 KEY 牌给到折戟再战。它不是只拆一张装备，而是让蔚玩家不敢安全投入护手和战斧，整个肉搏计划都会变慢。

皎月要主动选择战斗

赛后数据里皎月战斗获胜率更高，原因不是皎月更会拼数值，而是皎月总在自己能控制的地方发起进攻。

对局计划：把蔚从肉搏题改成费用题

全场通用

蔚最舒服的局面，是装备贴上去、单位打出过量、活跃以后再游走或继续压第二路。皎月要做的不是在每一路都比蔚大，而是让她每次进攻都缺一块：缺装备、缺费用、缺过量，或者缺下一轮手牌。

开局 保留折戟再战、换换乐、月之降临这类能改变结算的牌。不要只留大单位，因为蔚的胜路本来就是把战力做大。
中盘 优先拆护手和战斧的承载点。蔚的装备如果没人穿，手牌就会变成一堆无法进入战场的数值。
防守 看到蔚的超杀回合，先算能不能让它差一两点。只要过量三不成立，这回合就从爆发回合变成普通交换。
收口 资源领先以后不要空交答案。留一张回合外互动，让蔚重新手打装备时还要再吃一次干扰。
40:55 - 44:40 终局把蔚的总攻拆散

这段适合练防守计算：彗、薇古丝、盖牌和学生不是为了赢一个漂亮的大结算，而是让蔚的过量、断魂一扼和装备复用全部差一点。

皎月玩家复盘清单

  • 看到蔚保留红黄资源时，先问对面是不是要让装备和雷恩加尔完成过量三。

Review

皎月玩家最容易犯的错

  • 把折戟再战留得太久，结果让蔚先用护手或战斧抽到足够资源。
  • 看到法盾就不敢交专法，导致蔚下回合拿到更大的过量窗口。
  • 只处理最高战力单位，没有处理装备承载点和下一次活跃路径。
  • 废弃大厅回合只想着自己进攻，忘了用战力阈值卡住蔚的超杀。
  • 资源领先后把互动打空，让蔚最后一轮可以放心重装装备。

这场给皎月玩家的核心课是：对蔚不要恋战。你要赢的是结算方式，不是正面数字。只要蔚的装备和过量伤害连续被打断，肉搏卡组就会被拖进皎月更擅长的费用题。

Core

蔚视角先记住这五句话

猫岛巡礼.No.Jay选手展示了蔚的上限：雷恩加尔、战斧、顺劈和断魂一扼都能把数字做得很大。但这场也说明了蔚的难题：如果对手不跟你正面肉搏，你必须先处理“如何让装备安全落地”，再谈过量伤害。

装备要有第二承载点

第一局手里和场上的装备很多，但承载单位被皎月反复处理。蔚不能把所有价值都压在同一个单位上。

法盾不是绝对保护

皎月愿意顶法盾交牌时，蔚需要用这个信息判断对手手里还有没有后续互动，而不是默认法盾能挡一整轮。

过量窗口要提前铺

临时靠顺劈和断魂一扼补两三点，很容易被学生、彗或薇古丝卡住。蔚要在前一轮就让场面逼近阈值。

红黄要主动逼答案

红黄缺少魅惑和灵活回手，不能只等皎月进来。你需要用小单位和装备逼对手先交换换乐、折戟或专法。

别让折戟拆到节奏点

折戟再战拆掉护手或第一件关键装备时，损失的不只是战力，也是后续抽牌和费用安排。

破局框架：先骗互动，再把装备结算成两路威胁

全场通用

蔚打皎月不能只看“我这一拳有多大”。真正要问的是：对手的折戟、换换乐、月之降临和彗分别在哪里？这些答案没出来之前，最大单位也可能只是帮皎月确认该交哪张牌。

先手阶段 用较小单位和低风险装备试探，不要第一时间把护手和战斧都交到同一个单位上。
中盘阶段 如果折戟已经出现，立刻调整成多承载点路线，让皎月拆一件装备也不能拆掉整回合。
总攻阶段 顺劈、断魂一扼和雷恩加尔要服务于过量三，而不是单纯做大数字。先算对面能不能用学生或薇古丝把你卡在阈值外。
备牌思路 优先考虑能保护装备承载点、补手牌或迫使皎月提前交互动的牌。只加更多装备，可能让卡手问题更严重。

Practice

蔚玩家复盘清单

  • 装备上场前，确认还有没有第二个可用承载点，避免被折戟拆掉整个回合。
  • 用小单位先骗换换乐、月之降临或彗，不要把最大战力直接送进未知盖牌。
  • 每个捕猎场回合先算过量三，而不是只算战斗能不能赢。
  • 如果手牌里装备过多，优先找过牌和单位密度，别继续把资源压成单点。
  • 终局总攻至少多准备两到三点冗余，防皎月用学生、薇古丝或回手改变结算。
Review

蔚玩家最容易犯的错

  • 把护手和战斧看成必定能结算的资源，没有先确认皎月的拆装备数量。
  • 过早把雷恩加尔当唯一大哥，导致复仇、换换乐或专法处理后没有第二威胁。
  • 只计算自己的最大数字，没有计算皎月能让你差几分不过量。
  • 明知道皎月还有盖牌，仍然把总攻做成“刚好够”的路线。
  • 备牌只增加更大的装备，没有补充逼互动、保护承载点或持续过牌的手段。

这场给蔚玩家的核心课是：你不是没有上限，而是要先让上限安全落地。面对皎月这种灵活紫色套牌，装备、过量和游走必须分成两到三条威胁线，否则每次都会被一个互动拆成普通交换。
